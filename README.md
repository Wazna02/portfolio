## Run Locally

If you would like to explore or run this project on your computer:

**1. Clone the repository**

```bash
git clone https://github.com/Wazna02/portfolio.git
```

**2. Navigate to the project directory**

```bash
cd portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables (optional)**

Create a `.env` file using the provided example:

```bash
cp .env.example .env
```

Add your SMTP configuration if you want the contact form to deliver messages through email.

**5. Start the application**

```bash
npm start
```

**6. Open the application**

Visit:

```text
http://localhost:3000
```
